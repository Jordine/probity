# Bounded next experiment: cues, ambiguity and role drift

This is a proposal after the completed semantic review, before fresh probe or final judge outcome access. It changes nothing in the current 24-family, 48-episode evaluation and authorizes no calls. Keep all current cases, including mixed or uncertain ones.

| Issue | Diagnostic on the current frozen corpus | Smallest new intervention |
|---|---|---|
| Option cues | Describe option length, syntactic parallelism, specificity, negation and displayed-letter balance; compare the existing no-story controls by content choice and order. Order flips alone confound position effects with sampling variation. Use any already planned exact-message repeats to describe that variation. These are post hoc diagnostics, not a new primary model or case filter. | On new development families, pair the original option wording with a parallel formulation: same grammatical frame and comparable specificity, differing only in the answer-bearing fact. Keep question, source and gold meaning fixed. Cross both formulations with both displayed orders. Do not make the correct option systematically longer or more qualified. |
| Source ambiguity | Preserve the documented 124 proposal/order, 46 author-stance, 21 priority and 116 duration caveats. Report existing ambiguity tags and independent annotation disagreement/unknown coverage descriptively; keep the full denominator. Distinguish central-answer ambiguity from false quotations, attribution errors and local overclaims. | Audit new families before judge/probe outcomes: require an explicit actor, event/time reference and a supporting source passage. For example, ask what Porter **ordered**, rather than what was **proposed in a discussion**; distinguish elapsed time from time in a chamber. Keep interpretive questions as a separately specified stratum rather than silently rewriting them into factual lookups. Preserve an audit trail of revisions. |
| Role drift | Report the source8 Qwen3.8 final-turn switch and source41 advocacy-annotator error separately. Inspect the complete fixed qualitative sample and independently labelled mixed units. Answer-field adherence is not sustained prose advocacy, and assigned role is not local truth. | Compare current history formatting with explicit, consistently delimited prior-turn blocks carrying speaker identity, followed by an unambiguous current-speaker boundary. Keep the substantive advocacy/truth instructions and all source/history text unchanged. Retain every generated completion; semantic drift is an outcome, never a trigger to regenerate until compliant. |

Start with **eight new development families**, chosen without model outcomes. Test option wording first using the same Haiku no-story judge: two wordings × two orders × two identical-message repetitions gives **64 calls**. Add the corresponding full-source positive controls with a fixed Qwen participant checkpoint; both orders and wordings give **32 calls**. This is a small mechanism pilot, not evidence that no-story performance is at chance. Report all families and the uncertainty; do not retain only questions the judge misses. Use source-only review to verify that wording changes preserve the intended answer.

Only if that pilot warrants further work, test the single history-format intervention on the same development families: eight families × two Qwen participant models × two history formats gives **32 three-round debates**. Reuse the same valid private plans across the two formatting arms, with exact provenance. Blind prose audits and source-grounded local annotations measure drift and factual content separately. A disagreement or uncertain label remains in the results.

Retain the existing participant checkpoints, judge model, generation allowances, reasoning settings, round count, source-access rules, detector heads, DYL construction, thresholds, aggregation and matched-neutral presentation wherever the intervention does not require a change. Pair comparisons within source families and report effects by participant model; turns and paraphrases are not independent families. Re-audit complete contexts and local token coordinates after any message-format change.

Rewording the current questions or options and generating new continuations could be a useful **development diagnostic**, but cannot repair the existing benchmark or supply a clean confirmation set. Any selected wording or history protocol needs a separately frozen evaluation on **additional untouched families**, including source review before outcomes. Do not combine the option and history interventions into one unexplained change or spend on a larger sweep before these small tests establish what changed.
